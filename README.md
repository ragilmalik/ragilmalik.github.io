# Malik's portfolio

This is the source of my portfolio, live at `github.ragilmalik.com` and `ragilmalik.github.io`. It is a plain static site: one HTML page, one bundle of JS and CSS, a service worker for offline use, and two JSON files that feed it. No framework, no build step at deploy time.

## What's here

| File | What it does |
|------|--------------|
| `index.html` | The whole page. Sections: hero, journey, featured work, services, repository index, languages, about, contact. |
| `assets/app.js` | All the logic: loads the data, renders sections, runs the 3D background, handles the palette and case-study panels. |
| `assets/app.css` | All the styling. One dark theme, accent colour switchable. |
| `story.json` | Everything that describes me: the journey chapters, services, case studies, contact copy. Hand-written. |
| `repos.json` | Live GitHub data: profile, stats, repos, languages, timeline. Generated by the workflow, not edited by hand. |
| `sw.js` | Service worker. Pre-caches the app shell, and keeps `repos.json` / `story.json` fresh when online. |
| `manifest.webmanifest` | PWA manifest. The site is installable. |
| `404.html` | Custom 404, styled to match. |

## How the data stays fresh

`.github/workflows/sync-repos.yml` runs once a day. It calls the GitHub API for my public repositories, builds `repos.json`, and commits it only when something changed. The workflow output matches the exact shape the page expects, so the site never shows stale or half-written data.

## Running it locally

Python's built-in server is enough:

```bash
python -m http.server 8080
```

Then open `http://localhost:8080`. The page works from any static file server; there is no backend.

## Tweaking the content

- To change what the page says about me, edit `story.json`. The page re-renders from it; you never touch `index.html` for copy.
- The repository list, stats and language breakdown come from `repos.json`. To refresh them manually, run the workflow on GitHub (Actions tab, "Sync GitHub Repositories", Run workflow), or call the same API calls locally and regenerate the file with the same shape.

## Domain setup

- `github.ragilmalik.com` is a CNAME to `ragilmalik.github.io` on Cloudflare, and the repo's `CNAME` file declares the same. GitHub Pages serves both the custom domain and the default `.github.io` URL.
- The Pages source is the `main` branch, root folder.
